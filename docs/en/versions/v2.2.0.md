# v2.2.0

> A hardening release focused on production stability and developer experience — fixes several edge-case crashes and improves graceful degradation when signaling is unavailable.

## Highlights

- Fixed a null-pointer crash in `plugin-logger` when the ICE candidate is null.
- When the signaling server is unreachable, the publisher now keeps the local camera preview alive instead of tearing down all resources.
- Added a new `streamingstatechange: 'failed'` state for signaling-failure events.
- Fixed leaked PeerConnections caused by React StrictMode double-mount cycles.
- Added an `ErrorBoundary` component so a single component crash no longer whitescreens the entire demo page.
- Guards against DOM mutations from browser extensions (e.g. Google Translate) that break React reconciliation.

## Detailed Changes

### ICE Candidate Null Guard

- Added a null check for `candidate` inside the `onIceCandidate` hook of `plugin-logger`.
- Per the WebRTC spec, browsers emit a null candidate once ICE gathering completes. Before this fix, reading `.candidate` directly threw a `TypeError`.

### Graceful Degradation on Signaling Failure

- `RtcPublisher.start()` now wraps `createSession` in a dedicated try/catch layer.
- On signaling failure it calls `resetSession()` to clean up the dangling PeerConnection, but **leaves the local MediaStream untouched**.
- Callers receive `start() === false` and can keep showing the local video while only the uplink publishing fails.

### State Machine Extension — New `failed` State

- Added the `'failed'` value to the `streamingstatechange` event type.
- Extended the `onStreamingStateChange` hook parameter type accordingly.
- Consumers can listen for the `failed` event to implement custom failure UI and recovery flows.

### React Demo Hardening

- Added an `ErrorBoundary` component wrapping both the publisher and the player panels independently.
- `StreamPublisher` / `StreamPlayer` now register `useEffect` cleanup callbacks that call `destroy()` automatically on unmount.
- Fixes resource leaks triggered by StrictMode's mount → unmount → mount cycle.

### Google Translate DOM Conflict Guard

- The root element in `App.tsx` carries `translate="no"` and the `notranslate` class to opt out of translation extensions.
- Prevents translation plugins from rewriting real DOM nodes, which previously caused React's reconciliation to fail on `removeChild`.

## Compatibility & Migration Notes

- The `streamingstatechange` event now emits a new `'failed'` value. Consumers using exhaustive switch checks should add the new branch.
- No breaking changes to `plugin-logger` hook signatures. `onIceCandidate` will now also fire with a null candidate (ICE completion marker) — null-guard your own handlers as well.
- React demo cleanup is automatic; no migration steps required when upgrading.
